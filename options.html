not available? enable these flags
  1. Open chrome://flags/#prompt-api-for-gemini-nano → set to Enabled.
  2. Open chrome://flags/#optimization-guide-on-device-model → set to Enabled BypassPerfRequirement.
  3. Click Relaunch at the bottom of the flags page.
  4. Reopen this options page — the status above should update. The model (~2-4 GB) downloads in the background on first use.
